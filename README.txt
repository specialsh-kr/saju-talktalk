사주톡톡 14.0

쉽고 구체적인 사주상담형 PWA입니다.
- 사주팔자 / 오행 / 십신 / 대운 / 세운 / 월운 / 일진
- 궁합
- 날짜·시간 택일
- 상황형 상담
- 개인정보는 브라우저 기기 저장

14.0 방향
1. 화면은 크림색 한지 톤 + 짙은 적갈색 포인트로 단순화
2. 하단 탭 5개: 오늘 / 상담 / 좋은날 / 내사주 / 궁합
3. 답변은 결론 → 실제 사례 → 개인 사주 근거 순서
4. 설명용 상투문구를 줄이고 질문마다 구체 행동 예시 제공
5. 특정 역술가의 문장을 복제하지 않고, 대중 상담에서 유용한 직설성·간결함·구체성만 일반화해 반영
